# Sales Analytics Dashboard

This is a static website project for a responsive interactive sales analytics dashboard designed for a small e-commerce business.

## Features
- Responsive layout for desktop, tablet, and mobile devices.
- Interactive summary cards showing Total Revenue, Total Orders, Average Order Value, and Total Customers.
- Monthly sales chart and product category performance chart.
- Recent orders table with sample data.
- Dropdown filter to update dashboard data by product category.

## Setup
No setup is required as this is a static website. Simply open `index.html` in a web browser to view the dashboard.

## Usage
- Navigate through the dashboard using the header navigation links.
- View summary metrics in the summary cards section.
- Analyze monthly sales and category performance using the charts.
- Check recent orders in the table.
- Use the dropdown filter to view data for specific product categories.

## Deployment
This project can be deployed on any static hosting service such as GitHub Pages, Netlify, or Vercel.

## Note
This project uses sample data directly in JavaScript and does not require a backend or database.
