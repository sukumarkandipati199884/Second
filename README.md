# Business Landing Page

This is a responsive single-page business landing page designed for deployment on AWS S3 as a static website.

## Features
- Responsive layout with a modern dark UI
- Hero section with gradient background
- Services section with descriptions
- Contact form (demo only, data is not stored or transmitted)
- Mobile-friendly navigation

## Setup
1. Clone the repository.
2. Deploy the `index.html`, `styles.css`, and `script.js` files to your AWS S3 bucket configured for static website hosting.

## Usage
- Open the deployed URL in a web browser.
- Use the navigation to scroll to different sections.
- The contact form is a demo and does not store or transmit data.

## Deployment
This project is ready to be deployed to AWS S3. Ensure your bucket is configured for static website hosting and upload the files.
