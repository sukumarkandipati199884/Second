# Alex Carter - Portfolio

## Description
This is a responsive personal portfolio website for a software engineer named Alex Carter. It includes sections such as a navigation bar, hero section, About section, Skills section, Projects section with three sample projects, and a Contact section. The website features smooth scrolling and simple client-side interactions using JavaScript.

## Project Files
- `index.html`: The main HTML file containing the structure of the website.
- `styles.css`: The CSS file for styling the website.
- `script.js`: The JavaScript file for adding interactivity and smooth scrolling.

## How to Run Locally
To view the website locally, simply open the `index.html` file in a web browser. No additional build steps or server setup is required.

## Deployment Notes
This static website is suitable for deployment to AWS S3 and CloudFront or any other static hosting service. Ensure all files are uploaded and paths are correctly set for the hosting environment.
