# Sales Analytics Dashboard

This is a static website for a responsive interactive sales analytics dashboard designed for a small e-commerce business.

## Features
- Responsive design for desktop, tablet, and mobile devices
- Summary cards displaying key metrics
- Interactive charts for monthly sales and product category performance
- Recent orders table with sample data
- Dropdown filter to update dashboard data by product category

## Setup

1. Clone the repository.
2. Open `index.html` in your web browser.

## Usage

- Use the navigation links to jump to different sections of the dashboard.
- Use the dropdown filter to view orders by specific product categories.

## Note

This project uses sample data and does not require a backend or database. The charts are placeholders and can be implemented using a library like Chart.js.
